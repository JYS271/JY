# AGENTS.md

AI 에이전트(및 기여자)가 이 프로젝트에서 작업할 때 참고하는 가이드입니다.

## 프로젝트 개요

**오늘의 운세 뽑기** — 인형뽑기(크레인 게임) 형태의 웹앱. 코인을 넣어 뽑기 횟수를 충전하고,
집게로 이모지를 잡아 5번 두드려 깨면 그 안에서 한 줄 운세 + 행운 아이템이 나온다.

- 사용자: 개인용. 무언가를 하기 전/약속에 나가기 전 가볍게 보는 용도.
- 디자인: 다크 네이비 캐비닛 + 크롬 유리 케이스, 파란 모터의 크레인 집게, 애플 스타일 글로시 3D 이모지.

## 기술 스택 / 제약

- **순수 HTML / CSS / JavaScript. 빌드 단계 없음, npm 패키지 없음.**
- 외부에서 불러오는 것은 두 가지뿐:
  - 웹폰트: Google Fonts (`Gowun Dodum`, `Jua`)
  - 이모지 이미지: jsDelivr CDN의 `emoji-datasource-apple@15.1.2` (애플 스타일 PNG)
  - → 이모지 표시에는 **인터넷 연결이 필요**하다.
- **GitHub Pages로 배포**한다(아래 참고). 따라서 모든 경로는 **상대 경로**를 유지할 것. 빌드/번들러 도입 금지.
- UI 문구와 코드 주석은 **한국어**, 식별자(변수/함수)는 영어.
- 시각 효과는 **은은하게**(과한 반짝임 지양) — 사용자 요청사항.

## 실행 / 미리보기

빌드가 없으므로 `index.html`을 브라우저로 열면 된다. 단, `file://`에서는 일부 동작이 제한될 수 있으니
정적 서버 사용을 권장한다(예: `npx serve`, `python -m http.server`).

테스트 스위트는 없다. 변경 후에는 **브라우저에서 직접 동작을 확인**한다(콘솔 에러, 뽑기→깨기 전체 흐름, 코인/횟수).

## script.js 핵심 구조

- `FORTUNES` — 이모지 10종 + 한 줄 운세(`text`) + 행운 아이템(`item`) 배열. **운세 종이 내용은 뽑을 때마다 랜덤**으로 선택되고, 잡는 이모지는 집게 위치(캡슐)로 결정된다(둘은 분리되어 있음).
- `PILE` — 더미 배치 데이터. 각 원소 `{ x: 가로%, y: 바닥에서 띄운 px, s: 크기 px }`.
  - 좌→우 순서로 정렬되어 있고, **낮음/높음을 번갈아(지그재그)** 배치한다.
  - `s`(이모지 크기)는 개별로 다름. 크기를 바꾸면 이 값을 수정.
- 애플 이모지 렌더링 — 모든 이모지는 텍스트가 아니라 **배경 이미지**(PNG)로 표시한다.
  `EMOJI_BASE`, `emojiUrl(emoji)`, `setEmoji(el, emoji)` 헬퍼 사용.
- **집게 다리(2단)** — 윗마디(`.strut`, `LEG_L1`) + 팔꿈치 + 아랫마디(`.bone`, `LEG_L2`, 상대각 `LEG_LOWER_DEG`).
  - 하강 시 `OPEN_DEG`(60° → 양다리 사이 120°)로 활짝 벌어진다.
  - 잡을 때 `legAngleForSpan(이모지크기)`로 **손끝 간격이 이모지 지름과 일치**하도록 오므린다.
  - CSS의 `.strut`/`.bone`/`.lower` 값과 JS의 `LEG_L1/L2/LOWER_DEG`는 **반드시 일치**시킬 것(불일치 시 손끝 간격 계산이 틀어짐).
- **코인 / 뽑기 횟수(크레딧)** — `credits`(메모리 상태, 새로고침 시 0). 코인 클릭 → `insertCoin()` → `credits++`.
  뽑기 버튼은 `credits > 0`일 때만 활성(`setControls` / `updateCredits`). `drawFortune()` 시작 시 1 차감.
  횟수는 L/R 버튼 위 `.credit-panel`(`#creditCount`)에 표시.
- **뽑기 흐름** `drawFortune()` — (이전 결과/더미 정리) → 하강·개방 → 잡기·오므림 → 상승 → 중앙 이동 → `enterCrackMode()`.
- **깨기** — `CRACKS_NEEDED`(5)번 두드리면(`doCrack`) `shatter()`가 이모지를 조각내고 결과 슬립을 띄운다.
- 상태 플래그: `busy`(애니메이션 중 입력 차단), `crackMode`(두드리기 단계). 입력 핸들러는 이 둘을 확인할 것.

> 참고: 이전의 "하루 1회" localStorage 잠금은 코인/크레딧 도입으로 제거됨. `save/loadSaved/showLockedResult`는
> 현재 호출되지 않는 잔존 코드일 수 있으니, 손볼 일이 있으면 정리해도 된다.

## 변경 시 체크리스트

1. 순수 정적(빌드/의존성 추가 금지) 유지.
2. 이모지 크기/배치 변경 → `PILE` 수정. 집게 다리 형태 변경 → CSS와 JS 상수 동시 수정.
3. 브라우저에서 콘솔 에러 0 확인 + 코인→뽑기→깨기→결과 전체 흐름 확인.
4. UI 문구/주석은 한국어 유지.
